# Git/GitHub 2週間 勉強会

サークルの仲間で、Git と GitHub を **2週間（14日）** で身につけるための教材です。
前半はひとりで Git の基本を練習し、後半はチームで GitHub を使って、小さな「サークル紹介ガイドブック」を共同で作ります。

> [!NOTE]
> このリポジトリは **GitHub のテンプレートリポジトリ** として配布されています。2日目に、ここから「自分用のコピー」を作って使います。1日目はまだコピーがないので、このページをブラウザで読みながら進めてください。

---

## この勉強会の目的

- Git で「変更の記録（コミット）」「取り消し」「ブランチ」「マージ」ができるようになる
- GitHub にリポジトリを置き、`push` / `pull` で手元と GitHub を同期できるようになる
- チームで **Issue → ブランチ → プルリクエスト（PR）→ レビュー → マージ** の流れを回せるようになる
- コンフリクト（競合）が起きても、あわてずに解決できるようになる

## 対象となる人

- Git も GitHub も使ったことがない人（大歓迎です）
- 「名前は聞いたことがあるけれど、ちゃんと使ったことはない」人
- プログラミング経験は不要です。練習の素材は自己紹介やサークル紹介などの **文章（Markdown）** だけです

## 必要なもの（前提）

| 必要なもの                    | 補足                                                                  |
| ----------------------------- | --------------------------------------------------------------------- |
| Windows 11 のパソコン         | ソフトをインストールできること（管理者権限があると安心です）          |
| Visual Studio Code（VS Code） | インストール済みであること                                            |
| インターネット接続            | GitHub とのやりとりに使います                                         |
| メールアドレス                | GitHubアカウントの登録に使います                                      |
| スマートフォン                | GitHub の2要素認証（2FA）に使います（認証アプリをインストールします） |
| 1日あたり 30〜90分            | 日ごとの目安時間は下の表を見てください                                |

## このリポジトリの使い方

1. **1日目**：このページ（運営者のテンプレートリポジトリ）をブラウザで開き、[1日目](docs/day01-install-git.md) から始めます。
2. **2日目**：GitHubアカウントを作り、このテンプレートから **自分用のコピー** を作って、手元のパソコンにクローン（コピー）します。以降は VS Code で教材を開いて読めます。
3. **毎日の進め方**
   1. `docs/` にあるその日の説明ページを読みます（VS Code では `Ctrl+Shift+V` でプレビュー表示できます）。
   2. 説明ページの指示に従って、`exercises/` にある演習に取り組みます。
   3. ページ末尾の「確認チェックリスト」がすべてできていれば、その日は完了です。
   4. つまずいたら、ページ末尾の「よくあるつまずき」→ [レシピ集](recipes/README.md) → [困ったときは](#困ったときは) の順に頼ってください。
4. **9日目から** はチームでの作業です。運営者が用意するチーム用リポジトリを使います。チームで集まる時間（オンラインでも可）をあらかじめ決めておきましょう。

### 練習用フォルダの場所（全員共通）

この教材では、パソコンの中の作業場所を次のようにそろえます。説明ページのコマンドも、この場所を前提に書かれています。

```text
C:\Users\<Windowsのユーザー名>\git-practice\     （Git Bash では ~/git-practice）
├── gitlearn\               2日目：この教材の自分用コピー
├── my-profile\             3〜8日目：ひとりで練習するリポジトリ
├── conflict-lab\           7日目：コンフリクト練習用（スクリプトで作成）
├── my-profile-clone\       8日目：「もう1台のパソコン」役のクローン
├── gitlearn-team-<チーム記号>\   9〜14日目：チームのリポジトリ
└── appendix-lab\           任意：Appendix を読みながら実験する場所
```

`appendix-lab` は、Appendix のページで手を動かして試すときにだけ使います。ページごとに `appendix-lab/undo` のような専用フォルダを作り、使い捨てのリポジトリで実験します（フォルダ名は各ページに書いてあります）。

> [!WARNING]
> 「ドキュメント」や「デスクトップ」フォルダは OneDrive と同期されていることが多く、Git と相性がよくありません。上の場所（ユーザーフォルダ直下の `git-practice`）を使ってください。

## もっと知りたいとき・困ったとき

- **[Appendix（詳しい解説）](appendix/README.md)**：Git の内部のしくみ、設定、認証、改行コード、rebase などを深く知りたい人向けです。本編の各ページから関連する箇所へリンクしています。
- **[レシピ集（逆引き）](recipes/README.md)**：「直前のコミットを直したい」「push が拒否された」など、やりたいこと・エラーメッセージから引ける一覧です。
- **[演習の一覧](exercises/README.md)**：各日の演習と完了条件の一覧です。

## 困ったときは

1. まず、その日の説明ページ末尾の **「よくあるつまずき」** を見てください。
2. エラーメッセージが出たら、[レシピ集のトラブル対応](recipes/troubleshooting.md) で同じメッセージを探してください。
3. それでも解決しなければ、遠慮なく質問してください。
   - サークルのdiscordサーバーやDMなど

質問するときは、次の情報を添えると解決が早くなります。

- 何をしようとしていたか（何日目のどの手順か）
- 実行したコマンドと、表示されたメッセージの **全文**（スクリーンショットでも可）
- `git status` の結果

> [!CAUTION]
> パスワード、2要素認証のリカバリーコード、トークンなどは、チャットや Issue に **絶対に貼らないでください**。
